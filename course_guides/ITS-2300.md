# ITS 2300 Labs

Use the following guides to complete the question and answer section for the student's ITS 2300 class on Canvas.


# Network Design and Documentation
When required to assign and document IP address spaces according to the class best practices. You will need to develop a customized documentation per class. The Course IP Conventions are stated in the Lab Network Conventions section of each lab write-up.

## Screenshots

Lab report answers are text. Command line input and output is pasted into the LMS quiz as text, never as a screenshot, and Wireshark data is exported as plain text (``File -> Export Packet Dissections -> As Plain Text``), never captured as an image. Screenshots are accepted only where a lab question specifically asks for one. That is rare and almost always a graphical interface: a GNS3 workspace, a web page, or a tab in ENE or the firewall GUI. When one is requested, use the operating system's screen capture tool, not a phone camera.
